# Le Prof Maths — V4 couverture universelle déterministe

Cette version ajoute une couche complémentaire sans IA générative :
- primitives/intégrales usuelles et contrôle numérique des intégrales définies ;
- équations trigonométriques affines sin/cos/tan ;
- probabilités binomiales ;
- moyenne, médiane, variance, écart-type sur séries explicites ;
- géométrie métrique de base (Pythagore) ;
- branchement centralisé dans le routeur universel avant les solveurs spécialisés.

Aucun appel réseau ni modèle d'IA n'est ajouté.

La couverture ne signifie pas que toute démonstration libre, toute expression symbolique imaginable ou tout manuscrit OCR est résolu : les solveurs déterministes refusent proprement les cas hors domaine au lieu d'inventer une réponse.
