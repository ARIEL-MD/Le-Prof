# Le Prof V47 — Moteur universel des devoirs et exercices

V47 ajoute une couche déterministe de routage avant les solveurs spécialisés.

## Objectif
Identifier séparément :
- la famille disciplinaire ;
- le type de tâche demandé ;
- le niveau de confiance ;
- les signaux ayant motivé le routage.

Familles : mathématiques, physique-chimie, SVT, français, philosophie, histoire-géographie,
anglais, espagnol, allemand, EDHC, informatique, économie-gestion et autre.

Tâches : calcul, démonstration, résolution, correction, analyse, rédaction, traduction,
question de cours, QCM, vrai/faux, graphique/tableau.

Le routeur ne fabrique jamais une solution. Il ne fait que sélectionner ou restreindre
le domaine dans lequel un solveur local peut intervenir. En cas de couverture insuffisante,
Le Prof doit retourner un état non résolu plutôt qu'une solution inventée.
